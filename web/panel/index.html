Cómo crear el Firebase gratuito (5 min)

  1. Entra en console.firebase.google.com y crea un proyecto.
  2. Menú Build → Realtime Database → Crear base de datos. Elige una región y empieza en modo de prueba.
  3. En Configuración del proyecto → Tus apps → Web (</>), registra una app y copia el objeto firebaseConfig.
  4. Pégalo arriba (en «Configuración de Firebase») y pulsa Guardar y conectar.
  5. El mismo firebaseConfig va en el fragmento de «Mi página», que se rellena solo.

Nota: el «modo de prueba» deja leer/escribir a cualquiera durante unas semanas; está bien para empezar y probar. Para algo serio conviene añadir reglas de seguridad más adelante — te ayudo cuando quieras.
